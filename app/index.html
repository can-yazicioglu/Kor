ONE CLEAR CONTRACT · TWO EXPLICIT VERSIONS

The right context. Nothing extra.

The original 17-column schema remains supported. Version 2 appends two password reference-list flags for the separate risk policy, making 19 columns. Column names and order must match exactly. Use UTF-8, comma-separated CSV: at most 2 MiB / 10,000 events.

11 MODEL FEATURES

The learned context

Attempt counts, account spread, failure ratio and time / network / device context. The ML model uses only these eleven fields.

IDENTITY & EVALUATION

Kept outside the model

Three opaque tokens and timestamps support grouping. The target label and attack metadata never affect predictions.

2 OPTIONAL V2 FLAGS

A separate password rule

Exact reference-list match adds 25; near match adds 10. No plaintext passwords are included. A missing flag is unknown, not safe.

FieldPurpose
Missing history is not zero. An event with a missing feature or unsupported category remains unscored. If any event cannot be scored, its entire session remains pending. Otherwise the session shows its highest event score. This viewer consumes precomputed counters; it does not rebuild the two-minute window from a CSV.

LOCAL PROCESSING. EXPLICIT BOUNDARIES.

Transient data. Lasting care.

CSV is processed in browser memory and is never uploaded. No browser storage, analytics or third-party requests are used. The model JSON is fetched only from the same local server. Its checksum detects accidental corruption, not model authenticity. Imported data references are released after your chosen 5 / 10 / 15 minutes, on reset or when leaving the page. Suspended tabs recheck expiry on return. This is not a physical memory-wiping guarantee.

A temporary session

The production design uses a short-lived random session key. This demo creates no cookies and records no mouse or keyboard biometrics.

An opaque account

Use a customer identity provider's opaque ID instead of a username. Leave account_token empty if it is unnecessary. Format checks do not guarantee anonymity.

A measured response

Risk runs from 0 to 100; higher means greater risk. It is not a probability or safety guarantee. The demo never locks accounts or triggers real MFA.

Only demonstration inputs

Never put real credentials, raw IP addresses, customer records or leaked files into an AI conversation. Use the supplied synthetic CSV and public Vela demo credentials.

No real 30-day history is assumed. Persistent device fingerprinting and biometric tracking remain outside this prototype. V2 carries only reference-list result flags, never plaintext passwords or list contents.
